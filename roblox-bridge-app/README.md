# 🖥️ Roblox Universal IDE Bridge — Desktop Application

> Created by **[Esca-Byte](https://github.com/Esca-Byte)**

A modern, standalone Desktop GUI Dashboard and Sync Engine for the **Roblox Universal IDE Bridge**.

---

## ✨ Features

- ⚡ **Live Status Dashboard**: Pulse indicators for Studio connection health, tracked file counts, and active project paths.
- 📁 **Project Manager & Creator**: Switch between projects or create new ones with starter templates in 1 click.
- 🌳 **Interactive Script Explorer**: Tree navigation of all `.luau` / `.lua` files grouped by Roblox services (`ServerScriptService`, `ReplicatedStorage`, `StarterPlayerScripts`, etc.).
- 📜 **Live Activity Console Stream**: Real-time log streamer for Studio connections, file updates, and sync operations.
- 🛠️ **Quick Action Toolbar**:
  - **Open IDE**: Instantly launches VS Code / Cursor for your project.
  - **Open Folder**: Opens the project directory in Windows Explorer.
  - **Rescan**: Force rescans project files.

---

## 🚀 How to Launch

Simply double-click **`start-app.bat`** in the `roblox-bridge-app` folder!

Or via terminal:
```bash
cd roblox-bridge-app
npm install
npm start
```
Then open `http://localhost:7777` in your browser.
